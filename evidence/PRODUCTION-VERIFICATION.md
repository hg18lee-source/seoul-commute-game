## 같은 시작 카메라 비교

Chromium, 800×600, WebGL 2 / ANGLE SwiftShader Vulkan 소프트웨어 렌더링. 기존 Production과 통합 Preview에서 로그인 후 같은 공덕 스폰 좌표·카메라로 멈춰 샘플링했다. 6프레임 예열 뒤 20개 rAF 간격을 비교했다. API와 주 HTML을 제외한 Resource Timing의 압축 응답 본문 합계다.

| 지표 | 적용 전 Production | 통합 Preview |
| --- | ---: | ---: |
| 시작 화면에 필요한 정적 리소스 | 522,936B | 531,647B |
| 첫 코스 선택 시 추가 모델 응답 | 0B | 1,089,923B |
| 프레임 간격 중앙값 | 83.2ms | 83.4ms |
| p95 프레임 간격 | 150.0ms | 166.7ms |

운행 전체 프레임 시간과 하드웨어 GPU, GPU 타이머, 실제 VRAM은 미측정이다. 계단의 캐릭터 높이는 단차를 보간하며 개별 발의 전체 착지 프레임은 독립 검증하지 않았다. 자체 제작 역사 내부는 플레이 목적에 맞게 구성했다.

스크린샷은 본편의 공덕 시작 카메라에서 캡처했다. WEBM은 QA 계정으로 Preview 본편의 계단·개찰구·탑승 경로를 실제 조작한 영상이다. 로그인 입력과 비밀번호·세션 값은 영상에 포함하지 않았다.

재빌드·재배포와 자산 출처는 작업 트리의 `ASSETS.md`를 참고한다.
