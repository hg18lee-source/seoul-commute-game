# 주인공 캐릭터 검토

게임 원본 폴더에서 다음 명령으로 로컬 검토 화면을 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/character-review/character-preview.html`로 이동합니다. WebGL 2가 필요합니다. 방향과 거리 선택은 두 모델에 동시에 적용됩니다. 게임 카메라 버튼은 현재 실외 플레이 구도와 같은 카메라 위치, 수직 시야각, 시선 목표를 사용합니다. 비교 화면은 같은 조명에서 1차와 1.5차 GLB를 배율 1로 비교합니다.

## 모델과 재생성

- `model/commuter.glb`는 제공된 A 참고 이미지에서 의상과 실루엣을 참고해 직접 설계한 glTF 2.0 모델입니다. 외부 모델, 텍스처, 사진은 포함하지 않았습니다. 게임에 포함하고 공개 저장소에 게시할 수 있습니다.
- `python3 -B character-review/source/build_character.py`로 원본 메시와 뼈대에서 GLB를 다시 생성할 수 있습니다. 스크립트가 저장 용량, 삼각형 수, 재질 수, 뼈 수를 출력합니다.
- 모델은 약 1.8m의 중립 자세입니다. 루트, 골반, 척추, 가슴, 목, 머리, 좌우 위팔·아래팔·손·허벅지·정강이·발을 스킨에 연결했습니다. 팔꿈치·무릎 등 경계에 혼합 가중치를 설정했습니다. 모션 클립과 IK는 없으며, 관절을 크게 구부렸을 때의 변형은 후속 검증이 필요합니다.
- 참고 이미지와 비교해 가방은 조금 더 둥글고 재킷과 바지의 주름이 적습니다. 정면 얼굴을 단순화했고, 참고 이미지의 보행 자세 대신 비교와 리깅에 적합한 중립 자세를 사용했습니다.

## 비교 코드 및 라이선스

- `character-preview.html`, `preview.js`, `preview.css`는 비교 화면입니다. `source/legacy-preview.js`는 기존 게임의 캐릭터 생성 치수와 재질을 사용한 정지 비교 모델입니다.
- `vendor/loaders/GLTFLoader.js`와 `vendor/utils/BufferGeometryUtils.js`는 게임에 설치된 Three.js r180과 같은 리비전입니다. [Three.js r180 출처](https://github.com/mrdoob/three.js/tree/r180/examples/jsm)와 `vendor/THREE-LICENSE.txt`의 MIT 조건을 적용합니다. 기존 게임의 Three.js 코어를 공유합니다.
- `screenshots/`의 기존 PNG는 1차 검토 때의 캡처이고, `screenshots/refined/`의 PNG는 1차와 1.5차 GLB 비교 캡처입니다.

## 1.5차 개선본

- `model/commuter-refined.glb`는 기존 1차 제작 메시에서 수정한 별도 모델입니다. `python3 -B character-review/source/build_character_refined.py`로 재생성합니다.
- 재킷과 바지의 단면, 깃·앞섶·소매·밑단, 손·신발·머리 외곽, 가방끈을 다듬었습니다. 재질별 거칠기와 법선의 경계 각도를 조정해 큰 면의 삼각형 음영을 줄이고 날카로운 가장자리를 유지합니다.
- 162,808바이트, 삼각형 3,169개, 재질 12개, 텍스처 0개입니다. 인덱스 공유로 1차보다 파일 크기가 줄었습니다.
- 1차와 같은 18개 뼈 이름, 계층, 기본 위치를 유지했습니다. Edge에서 팔꿈치 약 41°, 무릎 약 42° 등 정지 자세를 적용해 스킨 버텍스 좌표와 가중치를 점검했습니다. 큰 각도·연속 동작에서의 옷과 가방 접촉은 아직 검증 범위에 포함하지 않았습니다.

## 2차 이동 모션

게임 원본 폴더에서 위 로컬 서버를 실행합니다.

- `http://127.0.0.1:8000/character-review/character-preview.html#motion-review`에서 Idle, Walk, Run을 선택합니다. 키보드 조작 버튼으로 초점을 옮긴 뒤 방향키와 Shift로 이동·달리기를 확인할 수 있습니다. 앞·옆·뒤 버튼은 검토 카메라를 바꿉니다.
- `http://127.0.0.1:8000/dist/`에서 본편을 실행합니다. 본편 카메라는 기존 고정 방향을 유지합니다.
- `screenshots/motion/`에 동일 카메라 비교 캡처와 Edge에서 실제 녹화한 WebM이 있습니다.

모션은 `dist/hero/motion.js`에서 기존 18개 뼈대에 직접 적용한 자체 제작 절차형 애니메이션입니다. 외부 모션 클립과 리타게팅은 사용하지 않았습니다. `dist/hero/commuter.glb`는 1.5차 검토본과 동일하고, Three.js r180 로더는 기존 MIT 라이선스를 따릅니다.

걷기·달리기는 착지 구간, 보폭, 발 높이, 팔꿈치와 상체 자세가 다릅니다. 두 다리의 발 위치를 역기구학으로 맞추고, 물리 스텝에서 측정한 이동 거리에 따라 발걸음을 진행합니다. 방향 전환은 모델의 회전만 보간합니다. 입력을 놓으면 위치는 즉시 정지하고 자세는 약 0.26초의 Stop 상태를 거쳐 Idle로 연결합니다. 착석·손잡이는 기존 상호작용용 간이 자세입니다.

현재 원본의 걷기 3.6m/s와 달리기 5.4m/s를 유지합니다. 기획서의 초기값 1.8m/s와 2.7m/s보다 두 배 빠릅니다. 빠른 보행 속도, 급반전, 충돌 및 짧은 전환에서는 발이 조금 미끄러질 수 있습니다. 발 위치 보정은 평면 기준이며, 맵에 맞춘 개별 발 접촉이나 손잡이·좌석 고정점은 이번 작업 범위에 포함하지 않았습니다.
