# 서울 거리 준실사 검토

게임 원본 폴더에서 로컬 HTTP 서버만 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/street-photoreal-review/street-photoreal-review.html`을 엽니다. 사진 구도 버튼에는 사진과 3D가 나란히 표시됩니다. 3인칭 이동을 누른 뒤 방향키와 Shift를 사용합니다. 보도·상점·역 입구·나무 구도와 상세/경량 품질을 선택할 수 있습니다. 모델 로딩 실패는 화면에 표시됩니다. 본편 카메라의 고정 오프셋, 시선 목표 및 48° 시야각을 검토 화면의 추적 모드에서 재사용했습니다.

## 사진 분석과 시안의 추정

- 고정 비교 카메라의 높이는 1.64m, 수직 시야각은 53°입니다. 보도 방향으로 거의 평행하게 보고 약간 오른쪽·아래를 향합니다. 실제 카메라 렌즈나 촬영 좌표는 알 수 없습니다.
- 회색 보도는 약 8.8m, 차도는 약 17m, 경계석 단차는 약 0.15m로 모델링했습니다. 입구는 카메라 앞 약 16m, 계단 시작 폭 약 3m입니다. 실측값은 사용하지 않았습니다.
- 가까운 보도 타일·도로 표시, 중간의 계단·가로수·상점, 먼 차도와 빌딩 실루엣을 분리했습니다. 낮 햇빛을 화면 왼쪽 위에서 들어오게 놓았습니다. 가려진 옆·뒷면, 실제 건물 깊이, 정확한 태양 방위와 촬영 시각은 사진 한 장으로 확인할 수 없습니다.
- 실제 건물·상호·역을 특정하지 않았습니다. 근경 상점의 파사드 뒤쪽과 반대편·원경 입면은 추정한 보조 지오메트리입니다. 지하철은 외부 진입부와 내려가는 계단을 표현하고 이동 안전을 위해 계단 구멍에 검토 전용 경계를 둡니다.

## 제작·재생성

- `scene.js`가 거리 모델, 재질, 512px 절차형 타일·아스팔트·석재 맵, 유리·금속용 환경 반사, 가지 및 잎 메시, 차체와 계단의 원본입니다. 새로고침하면 고정 시드로 재생성됩니다.
- `review.js`, `review.css`, `street-photoreal-review.html`은 로컬 검토 화면입니다. `captures/`에는 Edge 스크린샷 및 영상이 있습니다.
- 건물·차량·나무·표면 재질·가상 한글 간판은 자체 제작했습니다. 외부 사진 텍스처·모델을 가져오지 않았습니다. 기존 주인공 GLB와 애니메이션을 읽기 전용으로 사용했고, 정지 보행자는 같은 리그와 메시를 공유하며 의상 색과 크기를 달리했습니다. Three.js r180·GLTFLoader는 프로젝트에 포함된 MIT 라이선스를 따릅니다.
- 제공 사진은 `reference/street.png`에 검토용으로만 복사했습니다. 3D의 배경이나 재질에는 사용하지 않았습니다. 공개 사용 권리는 확인되지 않아 사진은 이 검토 폴더에서 Git 제외 대상으로 두었습니다. 파일을 옮긴 환경에서는 같은 경로로 별도 복사하면 됩니다.
- 인스턴싱과 거리별 디테일을 사용하고 투명 유리를 근경에 집중했습니다. 건물·나무의 정적인 그림자를 재사용하고 사람은 얇은 접촉 그림자로 표현합니다. 경량 모드는 픽셀 비율과 그림자 맵 해상도를 낮춥니다. 별도의 구역 스트리밍은 적용하지 않았습니다.

## 브라우저 성능

Edge 147에서 SwiftShader를 강제한 WebGL 2 세션입니다. 3인칭 시작 구도에서 16회 예열 후 상세·경량 각각 약 3.2초를 두 번 샘플링했습니다. 로컬 비압축 로드량은 약 2.90MB이며 참고 사진 약 0.54MB와 기존 Three.js 모듈·코어 약 2.01MB를 포함합니다. 사진을 제외하면 약 2.36MB입니다. 화면에 그린 삼각형은 약 7.85만 개, 드로콜은 475개, 장면 재질은 78개입니다. 하드웨어 GPU, GPU 시간 및 실제 VRAM은 미측정입니다.

| 품질 | 렌더 크기 | 프레임 간격 중앙값 | p95 두 번의 범위 |
|---|---:|---:|---:|
| 상세 | 1213×560 | 250.0–250.1ms | 250.1–265.6ms |
| 경량 | 1031×476 | 203.1–203.2ms | 218.8–281.3ms |

경량 모드는 같은 지오메트리를 사용하므로 드로콜과 삼각형 수는 같습니다. 소프트웨어 렌더링에서는 두 모드 모두 느렸습니다. 해상도가 낮을 때 중앙값은 개선됐지만 하드웨어에서의 결과를 보장하지 않습니다. 세미리얼 배경과 기존 로우폴리 인물 사이에 차이가 있으며, 레이어가 적은 상점 내부, 저디테일 원경 및 잎·차량 외형의 단순화가 사진과 차이를 만듭니다. 보행자는 정지 배치입니다.
